✳ How I work

How I apply AI to real workflows.

AI that survives production isn’t built once — it’s measured into existence. Six steps, in order, and then again.

Where it has run J&J MedTechsteps 1–4, FDA-regulated MemSurfall six, 0 → 99%+ reliable FotonVRsteps 3–5, Graph-RAG
↻and again
Step 01 Analyze the workflow Shadow the job. Trace where time and errors actually go.
Step 02 Understand the need A metric, a baseline and a counter-metric — agreed with the users.
Step 03 Build the gold standard Real inputs, ideal outputs, hand-checked — before any model.
Step 04 Apply AI The smallest system that works: prompt → RAG → agents, inside the existing stack.
Step 05 Test against the gold standard Score every change on quality, latency and cost. Guardrail what still fails.
Step 06 Ship, measure, iterate Production failures feed the gold set. Run the loop again.

Analyze the workflow; understand the need; build the gold standard; apply AI; test against the gold standard; ship, measure and iterate — then repeat.
